### 2️⃣ Раздел 1: Краткое описание проекта

#### 1.1 Суть проекта (2-3 предложения)

> Разработка консольной системы для анализа сетевого трафика, которая обрабатывает PCAP-файлы, извлекает JA4-фингерпринты из TLS-соединений и flow-признаки, применяет алгоритм Isolation Forest для обнаружения аномалий и формирует отчёт в CSV/JSON с оценкой anomaly_score для каждого потока.

#### 1.2 Бизнес-окружение (зачем нужен проект)

> Проект выполняется в рамках выпускной квалификационной работы (ВКР). Система решает актуальную проблему: традиционные методы анализа (DPI) не работают на зашифрованном TLS-трафике. FlowGuard позволяет выявлять аномальную активность без расшифровки данных, используя метаданные соединений и машинное обучение.

#### 1.3 Цель по SMART

**SMART = Specific, Measurable, Achievable, Relevant, Time-bound**

> **Цель:** Разработать консольную систему анализа сетевого трафика на Python и C++, способную обрабатывать PCAP-файлы, извлекать JA4-фингерпринты, выявлять аномалии алгоритмом Isolation Forest и выдавать отчёт с anomaly_score к **[дата защиты ВКР, июнь 2026]**.

Разбивка по SMART:
- **S (Конкретность):** Консольная система с определённым функционалом (PCAP → JA4 → ML → отчёт)
- **M (Измеримость):** Обрабатывает PCAP, выдаёт anomaly_score ∈ [0;1] для каждого потока
- **A (Достижимость):** Технологии известны (Python, C++, scikit-learn, Docker)
- **R (Актуальность):** Нужно для защиты ВКР, решает реальную проблему ИБ
- **T (Ограниченность по времени):** Срок — дата защиты

#### 1.4 Риски верхнего уровня

Кратко (подробности в Temp4):
- Недоступность качественных PCAP-датасетов для обучения
- Низкая производительность C++ парсера
- Переобучение ML-модели на тренировочных данных
- Изменение требований ВКР
