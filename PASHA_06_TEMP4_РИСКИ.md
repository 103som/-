## 📋 СТРУКТУРА ТАБЛИЦЫ

Колонки для реестра рисков:

| Колонка | Описание |
|---------|----------|
| Risk ID | Идентификатор (RK-001) |
| Risk Event | Событие риска (что может случиться) |
| Cause | Причина (почему это может произойти) |
| Consequence | Последствие (что будет, если случится) |
| Probability | Вероятность (High/Medium/Low или 1-5) |
| Impact | Влияние (High/Medium/Low или 1-5) |
| Risk Score | Оценка = Probability × Impact |
| Response Strategy | Стратегия ответа (Avoid/Mitigate/Transfer/Accept) |
| Response Actions | Конкретные действия |
| Trigger | Триггер (как понять, что риск реализуется) |
| Owner | Ответственный |
| Status | Статус (Open/Monitoring/Closed) |
| Req Link | Связь с требованием |

## 📝 РИСКИ ДЛЯ ПРОЕКТА FlowGuard

---

### RK-001: Недоступность качественных PCAP-датасетов
| Поле | Значение |
|------|----------|
| Risk Event | Не удастся найти качественные PCAP-файлы для тестирования и обучения |
| Cause | Датасеты закрыты, устарели или не содержат нужных типов атак |
| Consequence | Невозможно обучить и валидировать ML-модель |
| Probability | Medium (3) |
| Impact | High (4) |
| Risk Score | 12 |
| Response Strategy | Mitigate |
| Response Actions | 1) Заранее скачать MAWI, CTU-13, CIC-IDS-2017; 2) Подготовить собственные PCAP из тестовой сети |
| Trigger | Невозможность скачать датасеты за 2 недели до начала экспериментов |
| Owner | Самойлов П.П. |
| Status | Open |
| Req Link | R-001, R-006 |

---

### RK-002: Некорректные или повреждённые PCAP-файлы
| Поле | Значение |
|------|----------|
| Risk Event | Входные PCAP-файлы содержат ошибки или нестандартные форматы |
| Cause | Разные версии PCAP, битые файлы, нестандартные инкапсуляции |
| Consequence | Парсер падает или выдаёт некорректные данные |
| Probability | Medium (3) |
| Impact | Medium (3) |
| Risk Score | 9 |
| Response Strategy | Mitigate |
| Response Actions | 1) Реализовать валидацию входных данных; 2) Graceful degradation — пропускать битые пакеты |
| Trigger | Множественные ошибки при тестировании парсера |
| Owner | Самойлов П.П. |
| Status | Open |
| Req Link | R-015 |

---

### RK-003: Неподдерживаемые версии TLS
| Поле | Значение |
|------|----------|
| Risk Event | Некоторые TLS-соединения имеют версии, для которых JA4 не определён |
| Cause | Старый TLS 1.0/1.1, QUIC-соединения, нестандартные реализации |
| Consequence | Часть потоков останется без JA4-фингерпринта |
| Probability | Medium (3) |
| Impact | Low (2) |
| Risk Score | 6 |
| Response Strategy | Accept |
| Response Actions | 1) Помечать такие потоки флагом "flow-only"; 2) Документировать ограничения |
| Trigger | >20% потоков без JA4 в тестовом датасете |
| Owner | Самойлов П.П. |
| Status | Open |
| Req Link | R-003 |

---

### RK-004: Переобучение ML-модели
| Поле | Значение |
|------|----------|
| Risk Event | Isolation Forest переобучается на тренировочных данных |
| Cause | Недостаточная вариативность данных, неправильный подбор гиперпараметров |
| Consequence | Низкое качество детектирования на новых данных |
| Probability | Medium (3) |
| Impact | High (4) |
| Risk Score | 12 |
| Response Strategy | Mitigate |
| Response Actions | 1) Кросс-валидация; 2) Отдельная тестовая выборка; 3) Мониторинг метрик |
| Trigger | F1-score на тесте значительно ниже, чем на train |
| Owner | Самойлов П.П. |
| Status | Open |
| Req Link | R-006 |
