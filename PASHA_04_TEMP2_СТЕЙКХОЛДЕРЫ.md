## 📋 СТРУКТУРА ТАБЛИЦЫ

Заполни Excel-файл следующими колонками:

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор (S-001, S-002...) |
| Stakeholder | ФИО или название |
| Role | Роль в проекте |
| Organization | Организация |
| Interest/Concern | Интересы и ожидания |
| Influence | Уровень влияния (High/Medium/Low) |
| Power | Уровень власти (High/Medium/Low) |
| Communication | Канал и частота коммуникации |
| Engagement Strategy | Стратегия вовлечения |
| Owner | Ответственный за взаимодействие |
