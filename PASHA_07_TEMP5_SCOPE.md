## 1️⃣ ОПИСАНИЕ ПРОДУКТА

```
FlowGuard — система обнаружения аномалий сетевого трафика на основе 
машинного обучения и фингерпринтов JA4.

Система анализирует PCAP-файлы в оффлайн-режиме, извлекает метаданные 
TLS-соединений (JA4-фингерпринты) и статистику сетевых потоков (flow-признаки), 
применяет алгоритм Isolation Forest для выявления аномалий и формирует 
отчёт с оценкой anomaly_score для каждого соединения.

Целевые пользователи: исследователи информационной безопасности, 
аналитики SOC, разработчики систем защиты.
```

## 2️⃣ ГРАНИЦЫ ПРОЕКТА

### ✅ В ОБЪЁМЕ ПРОЕКТА (In Scope):

| # | Элемент | Описание |
|---|---------|----------|
| 1 | Парсер PCAP | Чтение и разбор PCAP-файлов, извлечение пакетов и метаданных |
| 2 | Извлечение логов | Формирование conn.log, tls.log, ja4.log |
| 3 | Формирование признаков | Агрегация в flows, расчёт flow-признаков, объединение с JA4 |
| 4 | ML-детектор | Isolation Forest для обучения без учителя |
| 5 | XGBoost (опционально) | Обучение с учителем при наличии разметки |
| 6 | Расчёт anomaly_score | Числовая оценка ∈ [0;1] для каждого потока |
| 7 | Классификация рисков | Преобразование в LOW/MEDIUM/HIGH/CRITICAL |
| 8 | Отчётность | Экспорт в CSV и JSON |
| 9 | Интерпретация | Указание 1-2 ключевых признаков |
| 10 | CLI-интерфейс | Командная строка для запуска |
| 11 | Docker-контейнер | Dockerfile для развёртывания |
| 12 | Документация | README, руководство оператора, ПМИ |
| 13 | Документация ВКР | Пояснительная записка по ГОСТ |

### ❌ ВНЕ ОБЪЁМА ПРОЕКТА (Out of Scope):

| # | Элемент | Обоснование |
|---|---------|-------------|
| 1 | Real-time анализ | Только оффлайн-обработка PCAP |
| 2 | Графический интерфейс (GUI) | CLI достаточно для целевых пользователей |
| 3 | Интеграция с SIEM | Требует отдельного проекта |
| 4 | IPS-функционал (блокировка) | Система только детектирует, не блокирует |
| 5 | Расшифровка TLS | Анализ только метаданных |
| 6 | Веб-интерфейс | Не предусмотрен ТЗ |
| 7 | Поддержка Windows | Только Linux/POSIX |
| 8 | Мобильное приложение | Не предусмотрено |

## 5️⃣ ТЕХНИЧЕСКОЕ ОПИСАНИЕ (АРХИТЕКТУРА)

### Подсистемы FlowGuard:

```
┌─────────────────────────────────────────────────────────────────┐
│                        FlowGuard                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌───────────────┐    ┌───────────────┐    ┌───────────────┐   │
│  │ PCAP Parser   │───▶│ Feature       │───▶│ ML Detector   │   │
│  │ (C++)         │    │ Extractor     │    │ (Python)      │   │
│  │               │    │ (Python)      │    │               │   │
│  │ ・conn.log    │    │ ・flow+JA4    │    │ ・Isol.Forest │   │
│  │ ・tls.log     │    │ ・statistics  │    │ ・XGBoost     │   │
│  │ ・ja4.log     │    │               │    │ ・scoring     │   │
│  └───────────────┘    └───────────────┘    └───────────────┘   │
│         │                                          │            │
│         ▼                                          ▼            │
│  ┌───────────────┐                         ┌───────────────┐   │
│  │ PCAP File     │                         │ Reporter      │   │
│  │ (Input)       │                         │ ・CSV/JSON    │   │
│  └───────────────┘                         │ ・interpret.  │   │
│                                            └───────────────┘   │
│                                                    │            │
│                                                    ▼            │
│                                            ┌───────────────┐   │
│                                            │ CLI Interface │   │
│                                            └───────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Технологический стек:
- **Python 3.x** — ML, формирование признаков, CLI
- **C++** — ускоренный парсинг PCAP
- **scikit-learn** — Isolation Forest
- **XGBoost** — опционально
- **Docker** — контейнеризация
- **Linux/Ubuntu** — целевая платформа
