## 📋 ЧТО ПИСАТЬ В КАЖДЫЙ РАЗДЕЛ

### 1. НАЗВАНИЕ ПРОЕКТА

```
Система обнаружения аномалий сетевого трафика на основе машинного обучения и фингерпринтов JA4 (FlowGuard)
```

---

### 2. ЦЕЛЬ ПРОЕКТА (ПО SMART)

**SMART = Specific, Measurable, Achievable, Relevant, Time-bound**

```
Разработать консольную систему анализа сетевого трафика на языках Python и C++, 
способную обрабатывать PCAP-файлы, извлекать JA4-фингерпринты и flow-признаки, 
обнаруживать аномалии с помощью алгоритма Isolation Forest и выдавать отчёт 
в формате CSV/JSON с anomaly_score для каждого потока.

Срок завершения: Защита ВКР в июне 2026 года.
```

---

### 3. ЗАДАЧИ ПРОЕКТА

1. Разработать подсистему парсинга PCAP-файлов с извлечением conn.log, tls.log, ja4.log
2. Реализовать формирование признакового пространства (flow-признаки + JA4)
3. Обучить ML-модель (Isolation Forest) для детектирования аномалий
4. Разработать подсистему отчётности с интерпретацией результатов
5. Упаковать систему в Docker-контейнер
6. Подготовить программную документацию по ГОСТ ЕСПД

---

### 4. ГРАНИЦЫ ПРОЕКТА (SCOPE)

#### ✅ Входит в проект:
- Оффлайн-анализ PCAP-файлов
- Извлечение JA4-фингерпринтов из TLS ClientHello
- Формирование flow-признаков (5-tuple, байты, пакеты, длительность)
- ML-детектирование аномалий (Isolation Forest)
- CLI-интерфейс
- Экспорт в CSV/JSON
- Docker-контейнеризация
- Документация по ГОСТ

#### ❌ НЕ входит в проект:
- Real-time анализ (только оффлайн)
- Графический интерфейс (GUI)
- Интеграция с SIEM-системами
- Блокировка трафика (IPS-функционал)
- Анализ расшифрованного трафика (только метаданные)
- Веб-интерфейс

- **Технологии:** Python 3.x, C++, Linux/POSIX

### 8. ДОПУЩЕНИЯ (ПРЕДПОЛОЖЕНИЯ)

- Доступны открытые датасеты PCAP для тестирования (MAWI, CTU и др.)
- Zeek или аналоги могут использоваться для генерации логов
- Научный руководитель доступен для консультаций
- Требования к ВКР не изменятся существенно

---

### 9. ЦЕЛЕВЫЕ ПОКАЗАТЕЛИ

| Показатель | Значение | Метод измерения |
|------------|----------|-----------------|
| Обработка PCAP | ≥ 10 MB за прогон | Замер времени |
| Точность детекции | Определяется экспериментально | F1-score на размеченных данных |
| Покрытие тестами | ≥ 50% | Coverage report |
| Документация | 100% по ГОСТ | Чек-лист соответствия |

---

### 10. ВЫСОКОУРОВНЕВЫЕ ТРЕБОВАНИЯ

1. Система должна принимать PCAP-файлы как входные данные
2. Система должна извлекать JA4-фингерпринты из TLS handshake
3. Система должна формировать flow-признаки для каждого потока
4. Система должна выявлять аномалии с помощью Isolation Forest
5. Система должна присваивать каждому потоку anomaly_score ∈ [0;1]
6. Система должна экспортировать результаты в CSV/JSON
7. Система должна работать в Linux-среде
8. Система должна быть упакована в Docker
